# The Wake-Up Call! — Gregory Arneaud

Homepage concept for *The Wake-Up Call!: How You Sleep Is How You Live* by Gregory Arneaud, by Astra Productions.

Static site, no build step. On Cloudflare Pages: framework preset **None**, build command empty, output directory `/`.

The page is set to `noindex, nofollow` while it is a preview. Remove that meta tag from `index.html` at launch.
